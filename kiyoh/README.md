# Kiyoh Reviews PrestaShop Module

This module integrates your PrestaShop store with Kiyoh/Klantenvertellen review platforms for automated product synchronization and review invitations.

## Features

- Automatic product data synchronization to Kiyoh/Klantenvertellen
- Automated review invitations based on order status changes
- Support for both Kiyoh.com and Klantenvertellen.nl platforms
- Multi-language support (English, Dutch, German)
- Comprehensive configuration options
- PrestaShop 1.7+ compatibility

## Installation

1. Upload the module files to your PrestaShop modules directory
2. Go to Modules > Module Manager in your PrestaShop admin
3. Find "Kiyoh Reviews" and click Install
4. Configure the module with your API credentials

## Configuration

After installation, configure the module with:
- Platform selection (Kiyoh.com or Klantenvertellen.nl)
- Location ID from your review platform account
- API Key from your review platform account

## Requirements

- PrestaShop 1.7 or higher
- PHP 7.1 or higher
- Valid Kiyoh/Klantenvertellen account with API access
